Cadenas de Conexión & Integración Externa

Usa estos parámetros para conectar tus aplicaciones (Python, Node.js, Power BI, Excel, DBeaver) a tu base de datos LocalDB.

PYTHON (pyodbc / SQLAlchemy) 
import pyodbc

conn = pyodbc.connect(
    r"Driver={ODBC Driver 17 for SQL Server};"
    r"Server=(localdb)\MSSQLLocalDB;"
    r"Database=JuiceCorner_DW;"
    r"Trusted_Connection=yes;"
)
cursor = conn.cursor()
cursor.execute("SELECT * FROM DIM_TIEMPO")
for row in cursor.fetchall():
    print(row)
NODE.JS (mssql) 
const sql = require('mssql/msnodesqlv8');

const config = {
  connectionString: 'Driver={ODBC Driver 17 for SQL Server};Server=(localdb)\\MSSQLLocalDB;Database=JuiceCorner_DW;Trusted_Connection=yes;'
};

async function test() {
  const pool = await sql.connect(config);
  const result = await pool.request().query('SELECT * FROM DIM_TIEMPO');
  console.log(result.recordset);
}
MICROSOFT EXCEL / POWER BI DESKTOP

1. Ve a Datos > Obtener Datos > De una base de datos > De SQL Server.

2. En el campo Servidor, escribe exactamente: (localdb)\MSSQLLocalDB

3. En Base de datos escribe: JuiceCorner_DW

4. En autenticación, selecciona "Usar mis credenciales actuales de Windows" y haz clic en Conectar.
